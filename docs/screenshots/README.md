## How they were produced

```bash
npm run build
npm run screenshots   # scripts/screenshots.mjs
```

The script creates a fresh demo repository, starts the local test harness (`src/main/harness/server.ts`) and drives Chromium with Playwright at 1440×900 (2× scale). The harness serves the same production renderer and calls the same `createApi()` / Git service used by the Electron app. It is a test/screenshot transport only and is not shipped in packaged builds.

The Electron window could not be launched in this Linux environment because GTK/X libraries and a desktop session are unavailable; therefore these are screenshots of the actual UI and real backend, not of the native window chrome. See `docs/TESTING.md` for details.

No personal files, credentials, tokens or private repository content appear in these images.
